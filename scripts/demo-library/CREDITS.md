# Demo library credits

The demo library holds no real video: `make.sh` generates a still frame with the title and silence, as long as the
real thing. Jellyfin then fetches posters, backdrops, logos and plots from [TMDB](https://www.themoviedb.org)
(this product uses the TMDB API but is not endorsed or certified by TMDB).

**Blender open movies** — © Blender Foundation, [CC BY](https://studio.blender.org/films/): Big Buck Bunny, Sintel,
Tears of Steel, Elephants Dream, Cosmos Laundromat, Spring, Sprite Fright, Charge, Agent 327: Operation Barbershop,
Caminandes 3: Llamigos.

**Public domain (United States)**: Nosferatu (1922), The General (1926), Metropolis (1927), Sherlock Jr. (1924),
The Kid (1921), The Cabinet of Dr. Caligari (1920), Safety Last! (1923), The Gold Rush (1925), A Trip to the Moon
(1902), The Phantom of the Opera (1925), Battleship Potemkin (1925). Many early episodes of Bonanza (1959) and
One Step Beyond (1959) are in the public domain; the demo only borrows the series' names and TMDB metadata.

**Pioneer One** (2010) — Josh Bernhard and Bracey Smith, [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/).
